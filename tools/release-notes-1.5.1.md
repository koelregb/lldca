# 浮乐 v1.5.1 — 去掉金额，专注规划 / 提醒 / 记录

这一版按「App 只负责规划、提醒、记录，不做账」的定位，把界面上的金额全部撤掉。

## 改动

### 1. 定投仓位比：不再出现任何金额

- 删除三格汇总：每月定投总额 / 本期建议投入 / 留存现金
- 标的行的「本期 ¥720」折算金额删除，只留名称、代码与占比
- 说明改为「只记比例不记金额」

### 2. 定投计划：只记标的与日期

- 计划行右侧的「¥2,000」改为「下次提醒 11-05」
- 新增 / 编辑表单去掉「每期金额（元）」与快捷金额按钮，只填名称、代码、每月定投日
- 到日通知文案从「英伟达 今日定投 ¥2,000」改为「英伟达 今日定投」
- 数据字段 `amount` 保留在本地与备份文件里，历史记录不会因为这次改动丢失

### 3. 定投页只剩两个子 tab（延续 v1.5.0）

定投计划 / 定投仓位比。已定投与收益从界面下线，数据仍可在导出文件里找到。

## 现在的页面职责

| 页面 | 做什么 |
|---|---|
| 定投计划 | 记标的、每月几号投、到日提醒 |
| 定投仓位比 | 记「谁占多少比例」，合计校验，市场温度给投入比例 |
| 加减仓 | 价格触发 / 定时提醒（仍显示行情价格，属市场数据非账户金额） |
| 财报 | 七巨头财报日期与倒计时提醒 |
| 红绿灯 / 复盘 | 纪律与记录 |
