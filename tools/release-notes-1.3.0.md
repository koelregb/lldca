## 浮乐 v1.3.0 — 五页重构 + 事件日历 + 授权体系

包名仍为 `com.lldca.app`（覆盖升级不丢数据），应用名更名「浮乐」。

### 走势
- 双子 Tab：**走势 / 日历**
- 四大指数（标普500 / 纳斯达克 / 恒生 / 上证），腾讯实时行情 60 秒自动刷新
- 三维度：全部至今 / 近一年 / 今日分时；卡片曲线支持拖动平移、滚轮 / 双指缩放、双击重置，点击看全屏大图（刻度轴 + 十字线 HUD）

### 事件日历
- FOMC 利率决议、每月非农 / CPI、选举、财报窗口自动标注
- 底部「+ 标记事件」自定义日程，点击日期查看当天，可删除
- 翻月浏览，事件按类型彩点标识

### 定投
- 定投计划管理（标的 / 代码 / 每月定投日 / 金额）
- 到定投日当天 9:00 自动推送本地通知

### 红绿灯
- 红线 · 禁忌 / 绿线 · 可重复 / 案例 三类心得，选色即录，保存自动切换列表

### 加减仓
- **信号提醒**：加 / 减仓价格触发监控，触达即推送通知
- **加减仓条件**：十道纪律题打勾，进度条，支持自定义题目 / 删除 / 重置，不限次数
- **恐慌级别**：十级情绪自评（谈笑风生 → 就当没买）+ Kübler-Ross 哀伤五阶段地图

### 我的
- 账号注册 / 登录（本机账号，密码 SHA-256 加盐哈希）
- 导出 JSON / 本机备份 / 从备份恢复
- 授权许可：试用 30 天，输入激活码永久解锁（多镜像 + 时间锚点防篡改）
- 关于：版本 / 检查更新

### 技术
- 授权码算法：HMAC-SHA256（WebCrypto），配套授权工具同算法生成
- 行情接口 qt.gtimg.cn；K 线真实数据（港股 / A 股）+ 公开锚点插值（美股指数，标注「演示」）
- 深色主题 / 红涨绿跌（A 股惯例）/ Service Worker 离线可用

> 试用到期后会显示激活界面，输入作者提供的激活码即可继续使用。
