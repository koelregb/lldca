# 浮乐 v1.4.0 — 中英双语（English version）

## 双语支持
- 新增 `i18n.js`：中文 / English 双语词条约 300 条，覆盖五个页面全部界面文案
- 「我的 → 语言 / Language」新增语言切换（中文 / English），切换后立即生效（页面重载）
- **首次打开自动跟随系统语言**：系统语言为中文用中文，其他语言默认英文
- 英文环境下桌面图标名称为 `Fuley`，中文环境仍为「浮乐」
- 中文模式不启用任何翻译钩子，行为与 v1.3.4 完全一致（零性能开销、零回归风险）

## 实现要点（供后续维护）
- 渲染层统一出口：语言为 en 时给 `Element.prototype.innerHTML` / `Node.prototype.textContent` 装钩子，所有 `render*` 函数输出自动过翻译，**无需在每处拼字符串时改代码**
- 静态 HTML 由 `applyStatic()` 在 DOM 就绪后扫描文本节点与 `placeholder/title/aria-label`
- 结构化拼接（如「第X康波 · 44年」「已收盘 MM-DD」「元/克」）改用 `L(zh, en)` 显式双语，避免中文数字与单位被机械替换
- 词典策略：整串精确 → 带数字的动态句式 → 长短语优先替换（保证「加仓」不被单字「加」误伤），单字只在整串相等时替换
- `app.js` 内 `L` 有兜底实现：`i18n.js` 缺失时自动回退中文，不会因脚本加载失败白屏
