# 浮乐 v1.5.2 — 精简为「规划 · 提醒 · 记录」

一次比较大的减法：把行情看盘、金额记账、价格提醒全部撤掉，只留定投规划、日历/财报提醒、纪律记录。

## 删掉的

| 内容 | 说明 |
|---|---|
| 走势页「股票」子 tab | 指数切换 + K 线主图 + 九宫格统计整体下线 |
| 走势页「VIX」子 tab | VIX 仪表盘下线（底层 VIX 数据仍用于仓位比计算） |
| 恒生指数、上证指数 | 从指数列表移除，仓位比不再引用上证分位 |
| 加减仓「信号提醒」子 tab | 价格触发 / 定时提醒下线，历史数据保留在导出文件里 |
| 定投金额 | 计划每期金额、仓位比折算金额、通知里的金额全部去掉 |
| 黄金页指标块 | 沪金现价 / 近一年涨跌 / 一年区间 / 均线 / 趋势信号 去掉 |

## 新增 / 调整的

- **顶部指数报价条**：走势页顶部常驻「标普500 / 纳斯达克」两张卡，显示最新价与涨跌幅（腾讯行情，60 秒刷新）。只有报价，没有那条插值演示的历史曲线。
- **日历财报月标黄**：含财报事件的月份整块月历浅黄底（#fdf6e3），财报日再加深一档、数字变琥珀色；底部说明注明「黄底 = 财报月 / 财报日」。
- **仓位比口径**：市场温度只取 VIX 分位（原先 0.6×上证分位 + 0.4×VIX 分位），说明文案同步改为「依据 VIX 情绪分位」。
- **原型同步**：`lldca-v1.3.0-mockup.html` 全量对齐，并修掉之前误删的红绿灯录入区、走势手势空引用导致的脚本中断。
