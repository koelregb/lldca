# 浮乐 v1.4.4 — 定投页「已定投」子 tab + 加减仓关联任意标的价格

## 新增
- **定投页新增「已定投」子 tab**（定投计划 / 定投仓位比 / 已定投 三个子 tab）：
  - 右下角 + 逐笔记录：股票名称、代码（可选）、定投日期、定投股价、定投数量；金额自动计算，可编辑 / 删除；
  - 同名同码记录自动合并为一个持仓：定投数量合计、加权定投股价、现价、市值逐项展示；
  - **现价自动联网更新**（腾讯行情，60s 随全局刷新）：填了代码即取价，不填则只统计成本；
  - 顶部汇总：累计投入 / 当前市值 / 浮动盈亏，列表显示浮盈浮亏比例——**红 = 浮盈，绿 = 浮亏**（A 股配色习惯）；
  - 支持 A股（沪 6/5/9 开头、深 0/1/2/3 开头、北交所 4/8/920）、港股（5 位）、美股（字母代码）。
- **加减仓「关联价格」升级**：
  - 新增「代码（可选，填了自动取现价）」字段——价格触发不再局限于四大指数，**任意股票 / ETF 都能加到提醒里**；
  - 表单新增「填入现价」按钮：点一下把该标的当前价填进触发价，再按心理价位微调；
  - 列表第二行实时显示 **现价 + 当日涨跌幅（红涨绿跌）+ 距触发幅度**，到价即触发本地通知（自定义代码同样支持）；
  - 未填代码时仍按名称匹配四大指数（标普500 / 纳斯达克 / 恒生指数 / 上证指数），老数据无缝兼容。

## 修复
- **行情代码转换规则修正**：上证 ETF（510300 等 5 开头）此前被误判为深市 `sz` 前缀导致取不到价，现已按沪（6/5/9）/ 深（0/1/2/3）/ 北（4/8/920）正确分流。
- 修复导出数据在 WebView 内静默失败：导出改为原生落盘（Filesystem → 文档目录 + 分享面板）。

## 优化
- 行情批量取价逻辑抽为公共函数，已定投与加减仓共用；切到对应页面、后台切回、60s 轮询都会自动刷新现价。
- i18n 补全新版文案（已定投 / 关联价格 / 填入现价等），中英双语完整。
