- 修复「自定义代码」入口位置：从弹层顶部移至**底部固定栏**（按钮栏上方），带「不在列表里？输入代码自定义添加」说明，手机软键盘弹出不再遮挡

- 全局键盘优化：监听软键盘高度，未 adjustResize 的环境自动将底部弹层抬至键盘上方
- 修复「我的-关于」页版本号仍显示 v1.1.0 的问题

## 使用路径

「计划」页 → 右上角 **+** →「选择定投股票」弹层 → **下方「自定义代码」**输入框 → 输入美股代码（1-5 位字母，如 NFLX / UBER / CRM，BRK.B 亦可）→「添加」→「完成」

## 安装

下载 APK 到手机安装（需允许未知来源应用），覆盖安装即可保留数据。
