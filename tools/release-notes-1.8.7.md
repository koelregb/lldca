## 浮乐 v1.8.7 · 闹钟真的会响了（含自检面板）

上一版换了通道和铃声，但仍然可能「条件满足却没声音」。这次找到三个实际原因并逐个改掉。

### 修了什么
1. **后台「消息通知」发到了已删除的旧通道**
   后台任务还在往 `fuley_alert` 投递，而上一版已经把这个通道删了。安卓对不存在的通道**直接丢弃通知**，所以后台命中时既没通知也没声音。现在改为 `fuley_alert2_<当前铃声>`。

2. **前台提醒依赖精确闹钟排期**
   原来用 `schedule.at = now + 700ms` 发通知，这条路径走 `AlarmManager.setExact*`；没有「精确闹钟」权限时会被系统降级甚至错过。现在改为**即时投递**（直接 `notify`），不再经过 AlarmManager。

3. **声音只依赖通知通道**
   通道一旦被系统/用户关掉就彻底静音。现在闹钟触发时**额外用原生播放器循环响铃**（`MediaPlayer` + 闹钟音量），前台响到点「我知道了」为止，后台响 12 秒——不依赖通知权限、不依赖通道设置。

4. **息屏响铃可能被省电休眠掐断**
   后台 `MediaPlayer` 循环播放 12 秒时，若未持唤醒锁，息屏/省电模式下 CPU 可能休眠、音频被冻结而响一半就停。现在补上 `WAKE_LOCK` 权限，并对前后台播放器都 `setWakeMode(PARTIAL_WAKE_LOCK)`，响铃期间 CPU 保持唤醒，保证把铃声播完。

### 复检补丁（WAKE_LOCK）
- Manifest 增加 `android.permission.WAKE_LOCK`
- `WatchCore.startRing` / `WatchPlugin.playTone` 均 `setWakeMode(PowerManager.PARTIAL_WAKE_LOCK)`
- 重新构建通过，APK 权限已用 `aapt dump permissions` 复核确认含 WAKE_LOCK

### 新增：闹钟自检
「通知提醒 → 闹钟不响？点这里自检」，一屏看完 8 项：
- 通知总开关 / POST_NOTIFICATIONS 权限
- 闹钟通道是否存在、重要度、是否被关、是否绑定音频
- 静音 / 振动 / 勿扰状态 + 是否授予勿扰例外
- **闹钟音量**（0 时怎么都不响，这是最常见的坑）
- 精确闹钟权限、省电白名单、上次后台检查时间与结果
- 上次通知发送失败的原因

底部四个动作：**响一次试试（8 秒）**、通知设置、声音设置、勿扰授权。

> 「响一次试试」直接播铃声、绕过通知通道：能听到 = 铃声与音量没问题，问题在系统通知设置；听不到 = 闹钟音量为 0 或处于勿扰。
