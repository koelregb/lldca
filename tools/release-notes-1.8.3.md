## 浮乐 v1.8.3 · 闹钟铃声可选

闹钟提醒不再是固定的一个音，两个入口都能改。

### App 内选（新增）
- 「加减仓 → 通知提醒」页面底部新增 **闹钟铃声** 一行，点开就能换，不用进新建表单
- 五档：**三短一长**（默认）· **滴滴** · **低沉** · **上行三音** · **跟随系统**
- 弹层里可直接「试听这个铃声」，选完保存立即生效

### 系统里改（新增入口）
- 铃声弹层里「**系统里改铃声 ›**」直接跳到「浮乐 → 通知」系统页面，按通道自选手机铃声
- 部分 ROM 不支持该跳转时，退回应用详情页；再不行显示三步路径引导

### 实现说明
- 安卓 8 以后通道声音创建后不可修改，因此每个铃声一个独立通道（`fuley_alarm_alarm / _beep / _deep / _chime / _system`），切换时建新、删旧，系统设置里不会堆重复项
- 「跟随系统」不指定音源，用手机默认通知音
- 新增原生插件 `AppSettings`（只做一件事：打开本应用的通知设置页）

### 提醒
- 先在 App 里发一次测试提醒，系统设置里才会出现「浮乐闹钟 · 当前铃声」通道
- 静音 / 勿扰会压掉声音；音量走「通知 / 铃声」，不是「闹钟」音量

### 安装
- Android 7.0+：下载 `fuley-v1.8.3.apk`（versionCode 55）
- 页面模型：`lldca-v1.8.3-mockup.html`
