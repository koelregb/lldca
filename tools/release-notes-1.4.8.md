# 浮乐 v1.4.8 — 价格按币种显示

## 本次改动

美股、港股不再错标成人民币，价格符号跟随标的市场：

| 标的类型 | 代码示例 | 符号 |
|---|---|---|
| A 股 / 沪深 ETF | 510300、600519、300750 | ¥ |
| 港股 | 00700、hk00700 | HK$ |
| 美股 | NVDA、usNVDA | $ |

### 覆盖位置

- **已定投**：定投股价 / 现价 / 市值 / 单笔定投价 / 单笔金额
- **收益**：按标的盈亏金额
- **加减仓提醒**：现价行、条件文案（涨到 $200.00）、到价通知正文
- **汇总与按月投入**：单一币种时显示对应符号；**同时持有 A 股与美股时合计不加符号**，并在「累计投入」标注「· 多币种」，避免把两种货币的金额误标成 ¥

> 定投计划里的每月投入 / 留存现金仍是 ¥（本币出资额，不涉及行情价格）。
