## 浮乐 v1.8.2 · 通知提醒（价格 / VIX）

「加减仓 → 加减仓条件」下线，替换为 **通知提醒**。

### 两类提醒
- **个股价格**：填代码（AAPL / 600519 / 00700），选「低于 · 等于」或「大于 · 等于」，填价格
- **恐慌指数**：直接对 VIX 设阈值，弹层里显示当前 VIX（28.18）

### 三种频率
| 频率 | 行为 |
| --- | --- |
| 仅一次 | 触发后自动关闭，需要手动再开 |
| 每日一次 | 每个自然日最多提醒一次 |
| 持续提醒 | 条件一直成立时每 5 分钟再响一次；回落再上穿立即响 |

### 三种送达（可任意组合）
- **消息通知**：系统通知栏消息
- **震动**：只振动，不响铃、不进通知栏（前台时附一条轻提示）
- **闹钟**：独立高优先级通道 + 自带提示音 + 振动 + **全屏弹窗**
- 三者可同时勾选：闹钟存在时只发一条通知（避免重复），振动按需叠加

### 其它
- 每 60 秒检查一轮，切回前台立即检查；每张卡可单独暂停/开启
- 设置里可「试一下这个提醒」，验证通知权限与铃声
- 新增权限：VIBRATE / POST_NOTIFICATIONS / SCHEDULE_EXACT_ALARM，新增 `res/raw/alarm.wav`
- 提醒只存在本机，随导出/备份 JSON 一起迁移

### 已知限制
完全退出 App 后，安卓不允许网页层继续轮询，因此**到价只在 App 打开（含后台切回）时检查**。需要 7×24 后台提醒要另加前台服务。

### 安装
- Android 7.0+：下载 `fuley-v1.8.2.apk`（versionCode 54）
- 页面模型：`lldca-v1.8.2-mockup.html`
