# 浮乐 v1.3.4 — 股票详情页 / 授权一年一签 / 加减仓计分

## 走势页首个 Tab 改为「股票」
- 子 Tab 文案「走势」→「股票」，界面上的「演示」标记已全部去掉
- 全新详情页结构（Futu 风格）：
  - 顶部 **四大指数切换条**：名称 + 最新价 + 涨跌幅，选中态高亮
  - **大字报价头**：指数名 / 代码 + 40px 主价格 + 涨跌额与涨跌幅 + 「已收盘 MM-DD HH:MM:SS」
  - **8 个周期**：分时 / 五日 / 日K / 周K / 月K / 季K / 年K / 更多
  - **面积主图**：昨收虚线基准 + 左侧价格刻度 + 右侧百分比刻度（含 0.00% 中线）+ 首/中/尾时间轴
  - **九宫格统计**：今开 / 昨收 / 最新 / 最高 / 最低 / 均价 / 振幅 / 涨跌 / 样本点数
- 周K / 季K / 年K 由日K、月K 按 ISO 周、自然季、自然年聚合（末值代表），带缓存
- 手势保留：拖动平移、滚轮/双指缩放、双击重置、单击看全屏大图

## 加减仓信号支持市盈率条件
- 表单新增 **P/E 条件**：`≤ 低于` / `≥ 高于` 二选一 + 数值（留空 = 不限）
- 列表与触发通知中显示在价格之后，如 `涨到 205.00 · P/E ≤ 12`
- P/E 条件随信号一起本地持久化，编辑时正确回填

## 加减仓条件拆成两个子 Tab，计分给结论
- 「加减仓条件」下新增 **加仓** / **减仓** 两个子 Tab，各一套默认 10 道题
  - 加仓侧重：计划内、触发条件确认、仓位上限、应急金、资金期限、估值分位、逆向波动、追高叙事、金额比例、复盘
  - 减仓侧重：计划内、触发条件确认、卖出理由、配置目标、近期开支、估值偏高、卖飞心态、贪婪叙事、卖出比例、复盘
- **计分规则**：打勾计 1 分，通过线 = 题数的 80%（10 题即 8 分）
  - ≥ 8 分 → 结论「加仓」/「减仓」
  - < 8 分 → 结论「不建议加仓」/「不建议减仓」
- 顶部实时结果卡：显示当前得分 / 总题数 / 通过线与判定文案，达标高亮
- 两套题独立存储（`fuley_quiz_buy_v1` / `fuley_quiz_sell_v1`），重置只影响当前侧
- 自定义题目只追加到当前所在侧，题数变化时通过线自动按 80% 上浮
