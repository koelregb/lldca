# 浮乐 v1.5.0 — 定投页精简 + 标的仓位占比

## 改动一：去掉「已定投」「收益」两个子 tab

定投页从 4 个子 tab 收敛为 2 个：**定投计划 / 定投仓位比**。

- 已定投（逐笔记录、浮盈浮亏）与收益（汇总、排行、按月投入）不再出现在界面
- 本地数据没有删除：`fuley.invests.v1` 仍保留在导出文件里，日后想恢复页面数据还在
- 相关的行情拉取、定时刷新同步下线，定投页不再额外请求个股报价

## 改动二：定投仓位比支持手动添加「股票名称 + 占比」

原来这一页只有一张按定投计划推导出来的分配表（占比由计划金额算出）。现在改成自己维护：

- **右下角 +** 打开表单：股票名称（必填）、代码（可选，自动转大写）、仓位占比（0.1%–100%）
- 列表每行显示「名称 + 代码、本期折算金额、占比」；点行可改名称 / 代码 / 占比，也可删除
- 顶部徽标实时显示 **合计**：合计 ≠ 100% 用橙色提示，超过 100% 标红
- 折算金额 = 本期建议投入 × 占比。本期投入 = 每月计划总额 × 仓位比（仓位比仍由上证位置分位 + VIX 情绪给出，可手动 50/70/100%）
- 数据存本地 `fuley.alloc.v1`，覆盖安装与重启不丢

示例：每月计划 ¥3,000、仓位比 80% → 本期投入 ¥2,400；英伟达 30% → 本期 ¥720。
