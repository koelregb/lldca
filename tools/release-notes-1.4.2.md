# 浮乐 v1.4.2 — 联网刷新修复 + 安装包签名修正

## 修复
- **走势页行情无法联网刷新（核心修复）**：Service Worker 旧策略对所有 GET 请求「缓存优先」，首次拉到的行情/K 线响应被写进缓存后，之后每次刷新都直接返回缓存里的旧数据，再也不走网络——表现为换了 WiFi/手机流量价格都不动。现已改为：
  - 跨域请求（腾讯行情 `qt.gtimg.cn`、K 线 `web.ifzq.gtimg.cn`、FRED 等）一律直连网络，不缓存；
  - 同源请求只缓存白名单静态资源（index/app/i18n/license/styles/manifest/icons），PWA 离线能力不受影响；
  - 旧缓存上线后自动清除，老用户升级后首次打开即解除冻结。
- **安装包签名结构修正**：v1.4.1 的安装包在打包流程中被二次重签，导致 APK Signature Scheme v2 签名块被剥离（`apksigner` 报 DOES NOT VERIFY），部分手机（Android 11+）安装提示异常。v1.4.2 改为直接使用 Gradle 原生签名产物（v1 + v2 完整、已 zipalign、单签名者），`apksigner verify` 通过，可正常安装与覆盖升级。
  - 说明：仓库开启了不可变发布（immutable releases）规则，`v1.4.1` 标签被系统永久占用无法复用，故修正版以 `v1.4.2` 发布；`v1.4.2` 与 `v1.4.1` 的应用代码完全一致（仅版本号与安装包签名结构不同）。
  - 证书指纹（SHA-256）与 v1.3.x / v1.4.0 完全一致（`8a8ac4a4…`），覆盖安装不会出现签名冲突。

## 优化
- App 从后台切回时立即刷新一次行情（10 秒节流），回到界面即可看到最新价格，不受网络类型影响。

## 校验
- SW 缓存策略冒烟测试 13 项通过；App 主逻辑冒烟测试 198 项通过。
- 安装包：`com.lldca.app` versionCode 13 / versionName 1.4.2，v1+v2 双方案签名，zipalign 对齐，包名不变可直接覆盖安装，注册信息与授权不受影响。
