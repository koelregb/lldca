## 浮乐 v1.8.0 · 我的 · 电子书

公众号 / 网页文章复制后粘贴即可存成一本，离线读、可归类、可导出。

### 新增
- 「我的」拆成 **设置 / 电子书** 两个子 tab，电子书状态随会话恢复
- 列表：标题、时间、来源三要素；自建栏目筛选 + 全文搜索；显示「读到 xx%」
- 新建：标题手填、时间自动生成、来源手填、正文粘贴；可选栏目
- **正文可上传图片**：相册选图 / 拍照，自动压到 1100px 宽再存本机
- 正文清洗：只留段落、小标题、引用、列表、表格行、图片，去掉公众号样式与「点赞在看」「长按识别二维码」等样板，重复段合并
- 阅读器：全屏阅读、A- / A+ 调字号、进度记忆、编辑信息 / 从头读 / 删除
- 导出：单篇与整库 → **Markdown / 网页（图片内嵌）/ 纯文本**，写入手机「文档」目录并可分享
- 电子书与栏目并入导出 / 备份 / 恢复 JSON

### 安装
- Android 7.0+：下载 `fuley-v1.8.0.apk`（versionCode 52）
- 页面模型：`lldca-v1.8.0-mockup.html`（手机壳内即当前版本 App 本体）

### 说明
- 数据仍只保存在本机；剪藏只留文字与图片，本地上传图片会先压缩，存储占用很小
- 公众号图片保留原链接，原站限制外链时会显示占位提示
